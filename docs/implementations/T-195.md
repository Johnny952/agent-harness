# T-195: agent-side settings — a `SubagentStop` return cap and `autoCompactWindow`

The decisions are `docs/decisions.md` ADR 510. This file is the plan; the
implementador adds *What was built* below it.

## Plan

One surface: the agent image's settings merge and the hook it registers.
No dispatcher change.

### 1. `hooks/cap_subagent_return.py` (new, stdlib only)

Everything it runs lives in this one file
(`docs/learnings/the-hook-is-copied-alone-into-the-agent-image.md`).

- Constants: `DEFAULT_CAP = 4000`, `CAPS: dict[str, int] = {}`,
  `DEFAULT_LOG_PATH = "/root/.claude/ia-harness/subagent-returns.jsonl"`,
  `SENTINEL` matching `<!-- ia-harness-role: <name> -->`, `SESSION_ROLE`
  matching a line starting `Role: <name>.` (the dispatcher's prompt line;
  for the mapper it is not the first line, so search the whole first prompt,
  multiline) and its `Task: <id>.` for the `task` field.
- `_first_user_text(path)`: first JSONL entry with `type == "user"`; its
  `message.content` as a string, or its `text` blocks joined. Missing or
  unreadable file → `""`.
- `_last_assistant_text(path)`: last entry with `type == "assistant"`, text
  blocks joined.
- `role_of(payload) -> (role, source, task)`: ADR 510 decision 4, sentinel
  in `_first_user_text(agent_transcript_path)` first, then `Role:` in
  `_first_user_text(transcript_path)`, else `("unknown", "none", None)`.
  `task` comes from the session prompt either way.
- `already_blocked(log_path, agent_id)`: a log line with `outcome ==
  "blocked"` and that `agent_id`; a missing log is `False`, a line that
  will not parse is skipped.
- `decide(payload, log_path, now=None) -> dict | None`: the text is
  `last_assistant_message` if a string, else `_last_assistant_text`.
  If `stop_hook_active` or `already_blocked` → append a `retried` line,
  return `None`. Else if `len(text) > cap` → append a `blocked` line and
  return `{"decision": "block", "reason": ...}`; the reason names the
  length, the role and the cap, and asks for the detail written to a file
  and a reply of at most `cap` characters that names that file's path, and
  says it is asked once. Else `None`, nothing written.
  Log fields exactly as ADR 510 decision 7; `ts` UTC ISO-8601; the parent
  directory is created; one `json.dumps` line appended per call.
- `report(log_path) -> list[str]`: one line per role, sorted:
  `role=<r> cap=<c> blocked=<n> retried=<n> retried_over=<n> max_chars=<n>`
  (`retried_over` counts retries still above their cap).
- `main(argv=None, stdin=sys.stdin, stdout=sys.stdout)`: log path from
  `IA_HARNESS_RETURN_LOG`, else `DEFAULT_LOG_PATH`. `--report` prints
  `report()`. Otherwise reads one JSON object from stdin, prints
  `decide()`'s dict as JSON when it is not `None`. Any exception: one
  `ia-harness: …` line on stderr, return normally (exit 0) — decision 8.

### 2. `hooks/install_settings.py`

### 4. Tests

`tests/hooks/test_cap_subagent_return.py` (new), building payloads and
JSONL transcripts in `tmp_path`:

- a return over the cap is blocked: `decide` returns the block dict, the
  log has one `blocked` line with `chars`, `cap`, `role`, `agent_id`;
- the retry with `stop_hook_active: true` is let through and logs one
  `retried` line, even while still over the cap;
- the retry with `stop_hook_active` false but a `blocked` line for the same
  `agent_id` in the log is let through too (block once holds on our record);
- a return under the cap returns `None` and writes no log;
- role from the subagent sentinel beats the session's `Role:` line; the
  session line alone gives `role_source: "session"` and the task id; neither
  gives `unknown`/`none` and `DEFAULT_CAP`; a `CAPS` entry (monkeypatched)
  is used for its role;
- the text falls back to the subagent transcript when
  `last_assistant_message` is absent;
- `main` on malformed stdin writes nothing to stdout and does not raise;
  `main` prints the block JSON for an overlong return;
- `report` over a log with blocked and retried lines gives the expected
  per-role line.

`tests/hooks/test_install_settings.py`: `test_install_registers_hook_on_every_event`
asserts `[HOOK_COMMAND]` on every event — keep that for every event but
`SubagentStop`, which carries `[HOOK_COMMAND, RETURN_CAP_COMMAND]`; add
`autoCompactWindow == 120000` on a fresh file and an operator-set value kept.
`tests/integration/test_agent_dockerfile.py`: assert the Dockerfile copies
`hooks/cap_subagent_return.py` to the path `RETURN_CAP_COMMAND` names.
