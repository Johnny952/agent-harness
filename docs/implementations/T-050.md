# T-050 — what a scoped commit leaves behind is recorded and shown

Decision: `docs/decisions.md` ADR 70. This note is how it was built.

## What was done

- `dispatcher/docker_exec.py`: `LeftBehind` (outside / excluded), `left_behind`
  (dirty paths after the commit, split by the excludes), `diff_of` (a
  `git apply`-able patch: `git diff --binary HEAD` plus a `--no-index` diff per
  untracked file; exit 1 from `--no-index` is success). `commit_worktree` and
  its two warnings are unchanged.
- `dispatcher/context_transfer.py`: `save_left_behind` / `clear_left_behind` /
  `read_left_behind` over `<scratch>/left-behind/<role>.json` and `.patch`; the
  patch is written first so a record never points at a missing patch.
- `dispatcher/dispatcher.py`: `_record_left_behind` right after the commit,
  wholly inside a `try` (a failure is a warning); `left_behind_report`;
  `_merge_task_branch` warns before merging.
- `dispatcher/cli.py`: the report lines go to stderr after `run-task` and
  `run-phase` (filtered to the role), and before `merge-task` with a line
  saying it merges anyway. Exit codes unchanged.
- Tests in the existing dispatcher files; `_FakeGit` gained `left_behind` and
  `diff_of` so no test reaches docker. The stale "nine" comment is "ten".
- Learning `docs/learnings/an-auditor-edit-outside-docs-never-lands.md`.

## Why this way

- One record per role, overwritten each run and cleared by a clean run, like
  `save_handoff`: a stale record must not outlive the run that replaced it.
- The record is taken from `git status` after the commit, so an excluded edit
  by an earlier writer is shown again under later roles; attribution is by
  commit, not author (ADR 70 Consequences).
- Nothing is committed: the scope exists so the auditor does not change the
  work after the review.

## Ruled out

- Committing the edits, or applying them at merge: out of scope for the task.
- Putting the paths in the handoff: roles write it, and the dispatcher's own
  observation is the one that cannot be forgotten.
- Failing `merge-task` when records exist: the operator may want the merge.
