# T-133-S1: board route and worker action for resolve conflict

Spec: `docs/decisions.md` ADR 285. Built on approve's route and handler
(ADR 267, ADR 264) and request changes' (ADR 272).

## What was built

- `dispatcher/actions.py`: kind `resolve_conflict` (`params` must be `{}`,
  serial key `base:<project>`, `spends_quota`, recovery `interrupt` with the
  half-made-merge error). Added to `_ONE_PER_TASK` and `_ONE_REVIEW_PER_TASK`,
  so a second of it, or one beside an approve or request changes, is 409.
- `board_service/app.py`: `POST /api/tasks/<id>/resolve-conflict`, through
  `_action` (the same guards as approve's: Origin 403, no token 503, bearer
  401, query 400, body 400). Refusals in order: unknown field, `check_new`,
  no task file 404, unreadable 400, merged 400, status other than `conflict`
  400 naming the status. Records `actor: operator`; writes no verdict line and
  no comment; starts nothing.
- `dispatcher/worker.py`: `_resolve_conflict` rereads the task (not in
  conflict, merged or gone is outcome `stale`, nothing runs), then calls the
  module helper `_resolve_locked`, which copies the CLI's block: container,
  base lock, owner read and restore, `core.resolve_conflict`. One dispatcher
  comment `resolve conflict, asked by <actor>: <detail>` for every outcome;
  `done` only for `resolved`, else `failed` with the first line as `error`.

## Why this way

- The helper is a module function so tests replace it; the CLI block is copied
  and not shared because `dispatcher/dispatcher.py` and `cli.py` are outside
  the task's surface. It calls the private `core._base_lock`.
- Serial key `base:` with `spends_quota` gives account-wait without the
  project flock: `_consider` takes a `ProjectLock` only for `project:` keys.
- No verdict line: a resolution is neither approve nor request changes.

## Ruled out

- Writing a `/verdict` kind or a verdict line (ties to a reviewed commit).
- A commit param (the worker merges into whatever tip the branch holds).
- Making the action cancellable while running (it holds the base lock and
  phases; a stopping worker waits for it).
