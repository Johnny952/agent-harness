# T-113 — the thread's `task_start` tool (ADR 187)

Implements `docs/decisions.md` ADR 187 as written; the file order was the
architect's plan.

## What was built

- `dispatcher/board_mcp.py`: `THREAD = "thread"`, the row
  `ROLE_TOOLS[THREAD] = ("board_list", "board_get", "task_start")`, and
  `mcp_config(..., turn=None)` which adds `&turn=<id>` to the query.
- `dispatcher/actions.py`: `_validate_start` accepts `thread` and `turn` in
  `params`, required when `actor == "thread"` and refused for any other actor,
  so `claim` re-checks them too. New `find(state_dir, action_id)` over
  pending/claimed/done; it does not create the queue and refuses anything that
  is not an action id before touching a path.
- `board_service/app.py`: `THREAD` in `KNOWN_ROLES`; `/mcp` requires a valid
  `turn` for the thread and refuses it for every other role (400); `task_start`
  runs the refusals of ADR 187, 4 in order, then `actions.create` with the same
  `ready` check as `http_start` (now `_ready_check`, shared). `_dispatch` and
  `_call` carry `(state_dir, token, turn)` as one optional `queue` tuple.
- `dispatcher/docker_exec.py` `turn_command(mcp_config=)` and
  `dispatcher/worker.py` `_turn`: with `board_mcp_url` set, the argv has
  `--mcp-config` (role=thread, turn=the action's id) and the three tool names
  after `TURN_ALLOWED_TOOLS`; with it null, today's argv.

## Why this way

- The turn id is in the URL the worker writes, not an argument, so the model
  cannot pick the turn that authorizes it. The mechanical guard on C-4 is that
  the running, operator-sent turn's text names the task as a whole token; the
  rest (did the message ask for a start) is the model's reading.
- Whole-token match is a lookaround regex, not a split on whitespace, so `T-1.`
  and `(T-1)` match while `T-10` and `T-1-S1` do not.
- Same queue: no parallel creator, so `_validate_start`, `_ONE_PER_TASK` and the
  readiness 409 apply unchanged; they come back to the model as `isError`.

## Ruled out

Thread/turn ids as arguments; a new `thread_start` kind; a cancel tool
(ADR 187, 9); a confirmation step in the console.

## Tests

`tests/board_service/test_task_start.py` (tool, record shape, every refusal,
token-boundary cases, `turn` query rule), plus rows in `test_actions.py`,
`test_board_mcp.py` and `test_worker.py` (argv with and without
`board_mcp_url`). Two existing tests were updated: the role-table equality and
the read-only-argv test, which now sets `board_mcp_url = None`.

## Not checked

The `--mcp-config` before the variadic `--allowed-tools` was not run against a
live `claude`; it follows `exec_claude`'s order.
