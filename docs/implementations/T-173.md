# T-173 — waitress lines printed once

## What

- The four `_log_waitress()` (`observability/collector/server.py`,
  `observability/api/app.py`, `board_service/app.py`, `config_writer/app.py`)
  now also set `logger.propagate = False`; the ADR 420 handler stays.
- `tests/conftest.py` fixture saves and restores `propagate` as well.
- The four stderr tests: the fake `serve` puts a stderr `StreamHandler` on root
  (standing in for waitress's `basicConfig()`), logs the two records, removes the
  handler in a `finally`. They assert each line once, `propagate is False`, one
  handler on `waitress`, root unchanged.
- README *Future work* line says "once (ADR 423)".

## Why this way

ADR 423 (amends ADR 420 Decision 3). `propagate = False` makes the output
independent of whatever root has, so it holds with or without waitress's
`basicConfig()`.

## Ruled out

- Dropping the handler (task's suggestion): output would then depend on waitress
  having configured root. See ADR 423 "Ruled out".
- Counting lines without a root handler: pytest's root handlers make
  `basicConfig()` a no-op, so the test installs its own.

## Verification

`python3 -m pytest` — see handoff.
