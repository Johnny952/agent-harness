# T-184 — `GET /api/credentials`

Builds ADR 456 *Consequences* 5; the contract is `docs/decisions.md` ADR 471.

## What

- `observability/api/app.py`: route `credentials` after `action_record`, constant
  `CREDENTIALS_STALE_SECONDS` (3 × `worker.CREDENTIALS_SNAPSHOT_SECONDS` = 900) and
  helper `_snapshot_stale`. It reads only through `dispatcher.credentials.read`.
- `data` is the file's object plus `stale` and `stale_after_seconds`; no file is
  `data: null` with a fixed warning; `SnapshotError` is `data: null` with its text.
- A missing, non-string, naive or non-ISO `written_at` serves the data, `stale: true`
  and a warning, as `_worker_heartbeat` treats `beat_at`.
- `tests/observability/test_credentials.py`: snapshot, stale, none, bad file (parse
  and non-object), bad `written_at`, future `written_at`, unknown parameter.
- `docs/README.md` api row lists the route.

## Why this way

- The module is imported as `credential_snapshot`: the view is named `credentials`
  and would shadow it inside `create_app`.
- `_worker_heartbeat` is not refactored; its shape differs (path, answer dict), so a
  small sibling helper is less risky than a shared one.

## Ruled out

- Touching `front/` (`FORWARDED`, route counts): ADR 456 task 7.
- A second parser or checking row shapes: the screen's `Malformed` owns that.
