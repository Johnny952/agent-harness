# T-164-S2 — `blocked_by` on a debt declaration

Decision: `docs/decisions.md` ADR 396 (carries out ADR 393, decision 3; ADR 393
is not edited).

## What was built

- `dispatcher/debt.py`: `Declaration.blocked_by`, `TASK_ID_RE`,
  `blocker_kind` (task / step / none), `blocked_by(row)` (the row's key, else
  the `Blocked by <value>;` lead of its **where**), `declared_row` carries the
  key, `filing_note` appends the lead instruction to gated entries (a plan
  step also says no backlog item is filed). `index_rows` is unchanged.
- `dispatcher/handoff.py`: `blocked_by` in the debt item, in `required`; the
  prose rendering shows `blocked by: <x>`.
- `dispatcher/tasks.py`: `propose_debt(depends_on=)`, checked by
  `_depends_problems`; `file_debt` per ADR 396 d.6. A task id it cannot read
  files with no `depends_on`; a plan step writes nothing. Results gain
  `blocked_by`, `gated`, `depends_on`.
- `dispatcher/dispatcher.py` `_mirror_filed_debt`: the declaration's
  `blocked_by` overrides the row's, so a row without the lead still files
  right; a gated result is logged as not filed.
- `dispatcher/cli.py` `_run_import_debt`: `after <task>`, `gated on <step>,
  not filed`, and `, <n> gated on a plan step` in the summary.

## Notes

- "Optional" is the empty string (ADR 396 d.1): the schema test requires every
  item field in `required`.
- The schema-size guard in `test_handoff.py` moved from 4096 to 4352; the
  revisor's schema, which restates debt, was 4205 with the field.
- Difference from the ADR text: in the summary line, gated rows are not also
  counted under "already filed" (the three counts add up to the total).
  "Filed" / "already filed" wording is otherwise unchanged.
- Tests: `test_debt_backlog.py` (kind, lead parsing, note, `file_debt` three
  cases incl. dry run, `propose_debt`), `test_handoff.py`,
  `test_dispatcher.py` (cycle mirror, three cases), `test_cli.py`
  (`import-debt` and `--dry-run`, three cases in one index).

## Ruled out / not done

- The role-prompt wording (S3); only `filing_note` tells the auditor.
- A `blocked_by` column in the index (ADR 396, ruled out).
