# T-156 — Restore keeps the versions it replaces and never follows a live symlink

Builds `docs/decisions.md` ADR 351, which amends ADR 328, 3.

## Plan (arquitecto)

1. **`dispatcher/backup.py` `_sync`.** First loop, per live name:
   - `_skipped(name)`: continue, as now.
   - `os.path.islink(live)`: if `name in wanted`, `_set_aside` it (the link
     itself; `os.replace` never follows); else continue. Check this before
     any `isdir`, which follows links.
   - otherwise as now: kept when `name in wanted` and `_same_kind`, else set
     aside.
   Second loop, the file branch: after copying to the temp file and before
   `os.replace(tmp, live)`, if `live` is a regular file (it is no link or
   directory by now) and `not filecmp.cmp(live, theirs, shallow=False)`,
   `_set_aside(live, aside_root, os.path.relpath(live, root), result)`. Equal
   bytes: no aside. `result.files` counts as before. Add `import filecmp`.
   Update the `_sync` docstring and the module docstring's last sentence:
   what the copy lacks and every live file it changes are set aside, and a
   live symlink is never followed (ADR 351).
2. **`dispatcher/cli.py`.** The `restore` help already says "setting aside
   what it replaces"; add `, 351` to its ADR citation. The output line is
   unchanged.
3. **Tests, `tests/dispatcher/test_backup.py`.**
   - Replaced version kept: back up, change `hive/tasks/T-1.md` to
     `"changed"`, restore; live holds the copy's `"task"` and
     `<aside>/tasks/T-1.md` holds `"changed"`. An untouched file
     (`board/T-1/description.md`) has no aside entry.
   - Unchanged tree: restore right after backup gives `result.asides == []`
     and no `.pre-restore-*` directory in either root.
   - Live symlink to a directory: an `outside` directory under `tmp_path`
     with a file in it; back up; replace `hive/board` with a symlink to
     `outside`; restore. `outside`'s contents are byte-identical to before
     and nothing new is in it; `hive/board` is a real directory again with
     the copy's files; `<aside>/board` is a symlink pointing at `outside`.
   - Live symlink to a file where the copy holds a file of that name: the
     target outside is untouched; the link is aside; the live name is a
     regular file with the copy's bytes.
   - A live symlink whose name the copy lacks is left in place, unfollowed.
   - Keep `test_restore_round_trip_sets_aside_and_keeps_directories` green:
     its changed `T-1.md` now also lands aside; assert that there.
4. **Docs.** `docs/cli.md` `restore`: files the copy holds are written over
   the live ones and a live version that differs is set aside first, files
   the copy lacks are set aside, a live symlink is never followed (ADR 328,
   351). Root `README.md` *Backups and restore*: the same in its words
   ("Files the copy lacks, and the live version of every file it changes,
   are moved to `.pre-restore-<time>/` ..."; a symlink is moved aside, never
   followed). `docs/README.md` *Modules* row for `dispatcher/backup.py`:
   "setting aside what the copy lacks and every live file it changes (ADR
   351)". Do not edit ADR 328.

## Implementation

Built as planned (ADR 351). `_sync` first loop: a live symlink is checked
before any `isdir`; the copy's name for it means the link itself is moved
aside (`os.replace` moves the link, never its target), otherwise it is left
alone. Second loop, file branch: when a regular live file differs byte for
byte (`filecmp.cmp(shallow=False)`) it is set aside just before the temp file
replaces it; equal files produce no aside. Docs: module docstring, `_sync`
docstring, `dispatcher/cli.py` help cite, `docs/cli.md` restore, root
`README.md` *Backups and restore*, `docs/README.md` Modules row.

Tests (`tests/dispatcher/test_backup.py`): changed file kept aside and
untouched file not; unchanged tree sets nothing aside in the hive; live
symlink to a directory not followed (outside tree identical, link aside);
symlink to a file replaced without touching the target; a symlink the copy
lacks left in place. `python3 -m pytest tests/dispatcher`: 3303 passed.

Ruled out: comparing mtime/size only (can miss a same-size edit); fixing the
wording to say overwrites are lost (loses data). Observed, not changed: in
the test fixture the state root's aside is never empty, so tests assert on
the hive side. Auditor's correction: the cause is not `actions/worker.lock`
(`*.lock` is `NOT_RECORDS`, left live) but the empty `actions/tmp`, `claimed`
and `done` that `worker.acquire` creates and the fixture's copy lacks
(`docs/learnings/a-restore-test-fixture-gets-a-state-aside-from-the-workers-own-dirs.md`).
The comment in `test_restore_of_an_unchanged_tree_sets_nothing_aside` still
names the lock; its assertion holds either way.

## Out of scope

Backup before each merge and nightly scheduling (T-147-D1); a symlink inside
a copy (`backup` never writes one); pruning `.pre-restore-*`.
