# T-054 — redact secrets in the hook

Rules are fixed in `docs/decisions.md` ADR 74; this records how they were built.

## What

- `hooks/emit_event.py`: one block of module constants (`SECRET_NAME`,
  `SHAPES`, `JSON_PAIR`, `ASSIGNMENT`, `SECRET_FILE`, markers) and
  `redact(event, env)`, which returns a new structure and walks dicts and
  lists, changing only strings. `main` calls it inside a `try` that wraps only
  `redact`; on any exception it posts `{"redaction": "[REDACTED:redaction-failed]"}`
  and prints the exception type only.
- `tests/hooks/test_emit_event.py`: one test per rule family, driven through
  `main()` with a fake `requests.post`.
- `docs/plans/backlog.md` item 6 bullet marked done.

## Why this way

- Standard library only, in the one file: the Dockerfile copies the hook alone.
- `redact` takes `env` as an argument so tests pass a deterministic env;
  `main` passes `os.environ`.
- Per-string order: secret-file, secret-field key, env values, shapes, JSON
  pairs, assignments. Shapes run before assignments so `GITHUB_TOKEN=ghp_…`
  is named by the more specific rule.

## Ruled out

- Hashing or prefixing the secret in the marker (leaks material).
- An off switch or an entropy heuristic (ADR 74).
- Redacting inside the collector: the secret would already have crossed the network.

## Notes

Over-redaction (`max_tokens=…`, `.env.example`) is deliberate. The agent image
must be rebuilt to pick the hook up.

## Known gap (found by the auditor)

ADR 74 rule 8 ("a value already redacted is not redacted again") is built as
`str.startswith("[REDACTED:")` in both `redact`'s `walk` and `_redact_text`,
so any string that merely *begins* with that text skips every rule, the
secret-file rule included. A prompt `"[REDACTED:x] ghp_…"`, or `cat .env`
whose stdout starts with a marker, posts the secret in clear. Measured with a
throwaway test under the task's hive directory. The fix is to skip only a
string that is exactly one marker (`fullmatch` of `\[REDACTED:[a-z-]+\]`),
with a test for each of the two cases; it is handed on as debt, since an
auditor's edit outside `docs/` does not land.
