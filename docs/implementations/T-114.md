# T-114 — the dock's composer and stop

Decisions are `docs/decisions.md` ADR 190; this records how it was built.

## What was built

- `front/src/lib/api/forward.ts`: the seventh board pair, `POST /api/threads/<id>/turns`.
  `boardTarget` matches `THREAD_TURNS`, decodes the id (undecodable → 404) and
  requires `THREAD_ID` (`main` or `th-<date>T<time>Z-<6 hex>`, a copy of
  `dispatcher/threads.py`) or answers 404. `action: "turn"` gives it the bearer and the
  CSRF checks; no `CONSOLE_PROJECT` needed. `forwardBoard` reads a turn against
  `MAX_TURN_BODY_BYTES` (128 KiB) and the others against 64 KiB; the body crosses
  unchanged. Module and function comments now say seven pairs / three action routes.
- `client.ts` `sendTurn`, `types.ts` `SendTurnBody`, `queries.ts` `sendTurnMutation`
  (refetches `["action-queue"]`).
- `lib/thread.ts`: `turn` items carry `action` (from `turn_start.action`); `tool` items
  carry `dispatch` (`__task_start`, no error, result JSON with string `id`/`task_id`);
  `queuedTurns` and `stoppingIds` read the queue defensively (`unknown` in, guarded).
- `chat-panel.tsx`: read-only banner removed; composer (textarea, Send, Ctrl/⌘+Enter),
  per-thread drafts in component state, queued turns after the history with Cancel,
  Stop / *stopping…* on a running turn, one error line (send and cancel errors),
  worker-stale and queue-error lines, archived → one line and no textarea,
  dispatch links (TanStack `Link` to `/tasks/$taskId` and `/queue`).
- `docs/plans/main-thread.md`: step 5 marked built, with *Talk about this task* and
  session seeding named open; step 6's dispatch-link sentence marked built.

## Why this way

- A queued turn has no log line until the worker claims it, so the queue (already polled
  by the Board under `["action-queue"]`) is the source; no new api route.
- Stop needs no state of its own: *stopping…* is derived from a pending/claimed `cancel`
  whose `params.target` is the turn id.
- The composer does not count characters; the route is the one enforcer, and the forward
  cap (6 bytes per code point worst case: 120,011 bytes) means the console never 413s a
  text the route would take. Tested with `"\u0001".repeat(20000)`.
- The dispatch `Link`s render only when `dispatch` is set, so the dock's tests without a
  router keep working; the link test mounts a memory router.
