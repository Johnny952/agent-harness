# T-182 — the worker's `git_token` and `account_login` handlers

Binding: `docs/decisions.md` ADR 456 decisions 5–6, ADR 459, ADR 462, ADR 465.

## What

- `dispatcher/docker_exec.py`: `open_docker_exec(..., stdin=False)` and
  `_docker_exec_argv(..., stdin=False)`; true adds `-i` after `exec` and a
  stdin pipe. The turn's call is unchanged.
- `dispatcher/credentials.py`: `_git_token` and `_account` renamed
  `git_token_row` and `account_row` (public), behaviour unchanged.
- `dispatcher/worker.py`: `_git_token`, `_account_login`, the `LOGIN_*`
  constants and fixed sentences, `_snapshot_after`; `_cancel` accepts a running
  `account_login`; `_keygen` refreshes the snapshot on every exit (its body moved
  to `_make_key`); `Worker.tick` sweeps `secrets/` first.
- `tests/dispatcher/test_worker_credentials.py`: the exec faked by `LoginProc`.

## Why this way

- **Secrets stay in locals.** Both handlers catch every exception themselves,
  because `Worker._guarded` writes `str(exc)` into the action's `error` and
  logs the traceback. The catch-all logs and records only the exception's type
  name; an `OSError` on the token write quotes `strerror` only.
- **The login output is scanned, never kept.** ADR 465 4 says a list in memory;
  only the URL is needed, and `script` echoes the pasted code, so the reader
  thread keeps the first URL and discards every other line.
- **One exception, `_LoginEnd`, carries a status and a fixed sentence** out of
  the straight-line handler; one `finish`, one log line and one snapshot follow.
- **Waits are slices of 50 ms on an event** so a cancel or a stop ends them at
  once; the code poll is `cancelled.wait(LOGIN_CODE_POLL_SECONDS)`.
- **The code is written as `code + "\r"` and stdin is left open** until the
  exec is stopped: closing it would send EOF into the pty before the CLI
  finishes.
- **Success needs the credentials file rewritten**: exit 0 is not trusted
  alone (`credentials.account_row` mtime against `claimed_at` to the second).
- **The release** is `operator.release_account` with no force; a refusal still
  ends `done` with `released: false`.

## Ruled out

- Force-releasing, a fake clock for the waits, the bare `script` argv with no
  pid line (ADR 465 *Ruled out*).
- Keeping the output buffer to quote in failures: it holds the echoed code.

## Not measured

The CLI's real URL, prompt and exit status under `script`, and whether SIGTERM
to `script` ends the CLI, need a container (ADR 465 *Consequences*).
