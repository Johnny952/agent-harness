# T-139 — stop counting the actions token's routes

Resolves `T-132-D1`.

## What

- `front/src/lib/api/server-env.ts`: the module comment's ADR 157 paragraph and
  `BOARD_ACTIONS_TOKEN`'s doc comment no longer say "two" or "start and cancel".
  They name the routes as those `forward.ts`'s `boardTarget` resolves with an
  `action`, listed in `forwardBoard`'s doc comment.
- `docs/debt/`: a resolution row appended to `README.md`, `T-132-D1.md` Status set
  to resolved, a paragraph appended to `log.md` (ADR 297).

## Why this way

Pointing at where the routes are decided, as T-132 did for
`BOARD_SERVICE_URL`, means the comment cannot go stale when a route is added.

## Ruled out

- Listing the routes in `server-env.ts`: that is the next stale count.
- Touching the header's "seven names": it counts env vars, not routes.
- Editing the open `T-132-D1` row: ADR 297 makes the index append-only.
