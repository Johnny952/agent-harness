# T-143 — Quota from the stream's `rate_limit_event`

Decisions are `docs/decisions.md` ADR 312; this note is how it was built.

## What was done
- `dispatcher/docker_exec.py`: `ClaudeResult.rate_limit_event` (default
  None); `exec_claude(stream=True)` ends its argv `--output-format
  stream-json --verbose`; `_parse_stream` reads stdout whole when it is one
  `result`-typed (or untyped) object, else line by line, keeping the last
  `result` as `raw` and the last `rate_limit_event` whole.
- `dispatcher/quota.py`: `usage_from_rate_limit_event`, `retry_at_from_event`,
  `STREAM_READING_FRESH_SECONDS = 900`. Resets are written as the `/usage`
  clause (`%b %d, %I:%M%p (UTC)`) so `parse_reset` and `week_ceiling` run
  unchanged.
- `dispatcher/state_machine.py` (outside the card's Surface; ADR 312, 6
  needs it): `retry_at` beside `rate_limited_at` in `record_rate_limit`,
  `_write_account`, `clear_rate_limit`, `get_retry_at`.
- `dispatcher/dispatcher.py`: `_quota_decision` and `_probe_record` take
  `source`/`read_at`; `_fresh_stream_usage`, `_record_stream_usage`,
  `_refusal_hold_until`; `_read_usage` returns `("stream", (usage, read_at))`
  before any exec; `_recheck_cooling_accounts` uses a fresh reading read
  after the refusal; `dispatch_phase` and the four resumes stream, record
  after the phase and pass `retry_at` on a refusal.
- Docs: ROADMAP D2 run note, README *Stop probing quota* and *Retry at the
  CLI's reset time* (built), `config.example.yaml` cooldown comment.

## Why this way
- `source`/`read_at` ride on the existing `last_probe` record: no new state
  key. They stay out of `PROBE_KEYS`, so records written before this load.
- Reusing a reading records it with its original `read_at`, so freshness
  never renews itself and the probe runs again after 15 minutes.
- A one-line stream that is only a `rate_limit_event` must not be read as
  the result, hence the type check in `_parse_stream`.

## Ruled out
- Parsing in `docker_exec` (the card forbids it).
- Treating a missing window as 0% (ADR 312, 3).
- Removing the `/usage` path (out of scope).

## Not done
- `dispatcher/operator.py` status still counts the cooldown from
  `quota_cooldown_seconds` and ignores `retry_at` (declared as debt).
- Not verified against a live stream beyond the D2 sample; the `result`
  line's keys in `stream-json` are assumed equal to `json`'s.
