# T-042 — the card for the usage route's screen

`T-024-D3` said `GET /api/tasks/<task_id>/usage` (`docs/decisions.md` ADR 54)
had no screen and no card saying which page would show it or what it prints.
This task writes that card. It builds nothing in `front/`.

Written by the arquitecto on 2026-10-14 against base commit `8505970`.

## Decisions

1. **The card is `docs/plans/front.md` *The usage task: what a task's
   `claude` calls cost***, written by the arquitecto in tier 2. It is tier 2
   because ADR 54 grew the route the way T-013 and T-016 grew theirs. It is
   not tier 1, which is closed, and not tier 3, since there is no write and
   no privilege. The plan's Status paragraph gets one sentence pointing at it,
   and the *Deferred decisions* table gets one row for the served total.
   Tier 2's *Done when* paragraph is a record and is not edited; the card says
   it came after that paragraph.
2. **The screen is a region of the task detail**, under the phase timeline.
   The card gives three reasons: the route is one task's resource and refuses
   the same ids as the detail route; an attempt is a role and a round, which
   the timeline already lists; and a cross-task view would need a sum no route
   serves.
3. **It ships with per-line figures and does not wait for a total.** The
   console computes nothing: no sums, no differences between lines, nothing
   across groups. That holds even for the two figures ADR 64 makes correct
   (the token sum and the last line's cost), so that a new ADR changing the
   route's answer cannot leave a console copy of the old rule behind. A total
   arrives later as a new key under its own ADR, and the screen prints it
   verbatim. Each line's `total_cost_usd` is headed *session cost so far*.
4. **Failover and unmeasured lines** read as the card says: groups that share
   a role and a round are drawn together as numbered attempts, a changed
   account is marked *failover from <account>*, and a `measured: false` line
   reads *no result: crashed or timed out*, never zeros. A null `phase_call`
   prints *no phase line in this attempt*.
5. **No `docs/ui.md` entry is needed.** Every state the region has maps to an
   entry that exists. Figure formatting is left to the Usage task as a
   one-screen choice.
6. **No ADR.** The card decides only about the console. The total key is a
   later task's ADR, which is outside this card's scope.
