# T-125-S3 — the console's *Approve*

Design: `docs/decisions.md` ADR 270 (on ADR 258, 264, 267). Front only; no new
package, no build.

## What was built

- **Forward** (`front/src/lib/api/forward.ts`): `POST /api/tasks/<id>/approve`
  is the twenty-second board write, `action: "approve"` in `boardTarget`'s
  `actionRoutes`, with the actions bearer. `approveBody` rebuilds the body from
  `project`, `commit` and `text` only (else 400); `project`, when present, must
  match `PROJECT_SLUG`; absent it is `CONSOLE_PROJECT`, and with neither the
  console answers 503. Order: token 503, 413 cap, body 400, project 503. The
  prose counts for board writes moved 21 to 22 (fifteen pairs, last eight with a
  bearer); the api read whitelist's "twenty-one" is untouched.
- **Client** (`client.ts`, `types.ts`, `queries.ts`): `approveTask`,
  `ApproveTaskBody/Result`, `approveTaskMutation` (refetches the task's
  comments, the board and `["action-queue"]`). `ApiError` gained an optional
  `body`, set by `readBare` on a non-ok answer, so the screen can read `verdict`.
- **Screen** (`routes/approvals.tsx`): *approve* beside *comment verdict* in
  the verdict form, sending the tip the diff shows. Disabled on the Conflict
  lane (title names *resolve conflict*), on `merged !== false`, over the comment
  limit, while a post is pending, and after a 201 at this tip (*approve
  queued*, local state). Not drawn without a diff. Toasts: 201 names the
  action; a refusal whose body has `verdict` says it was recorded but nothing
  was queued. `approveOutcomes` (`lib/review.ts`) lists the dispatcher's
  `approve at ` comments under *outcomes*.
- **Docs**: `docs/plans/review.md` Status and step 7.

## Why this way

- Rebuilding the body (as a start's) keeps the route's fields the only ones that
  cross; a browser `project` is kept because the diff was read from that task's
  clone (ADR 270, 1).
- `ApiError.body` is optional, so other callers stay source-compatible.
- Outcomes are read from the comments the screen already polls, not from the
  action.

## Ruled out

- `CONSOLE_PROJECT` always (the diff came from the task's own clone); a
  separate approve text box; polling `GET /api/actions/<id>` for the outcome
  (ADR 270, Ruled out).
