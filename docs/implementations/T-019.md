not exist in this repository and installing it is not authorised". That clause

outside the repo and gone with the task.

Documentation, the debt index and the ADR only. No source, test or
configuration file moved: `front/vite.config.ts` is untouched
(`docs/charter.md` **C-9**), and so is everything under `front/src/`,
`dispatcher/`, `observability/` and `tests/`. `docs/charter.md` is human-owned

## One bullet of ADR 46 was corrected rather than transcribed

ADR 46's *Context* said every phase installs "in their own worktrees", so "a
previous phase's install does not reach the next one". The install it describes
proves otherwise: this phase's came back `Checked 512 installs across 549
packages (no changes) [13.00ms]` against the arquitecto's `486 packages
installed`, in the same worktree, with its `node_modules` still filled.

`dispatcher/docker_exec.py:create_worktree` is why.
`WRITER_ROLES` — cartografo, arquitecto, implementador, auditor — are checked
out at a shared, persistent `worktrees/<task-id>/work`, deliberately, so that
"the implementador starts from what the arquitecto left rather than from a
pristine HEAD". Only a reviewing role gets `worktrees/<task-id>/<role>`, and
that one is dropped and rebuilt before every add. So gitignored state survives
between writer phases and never survives into the revisor's.

The bullet now names that mechanism. The entry it cited,
`/data/.hive/learnings/inbox/T-018-each-phase-worktree-needs-its-own-bun-install.md`,
was written by T-018's **revisor** and is correct where it stands; its *Why*
generalised one role's path to all four, which is how the claim reached this
ADR. `/data/.hive/learnings/inbox/T-019-only-the-revisor-gets-its-own-worktree.md`
carries the narrowing and the evidence, with `refutes:` pointing at it — the
auditor rules on both.

Editing ADR 46 in place rather than appending a 47th is what the arquitecto's
own handoff asked for: the entry is this cycle's and unmerged, so a correction
inside the task is an edit and not a second decision. Nothing else in it moved,
and the decision itself is untouched — the bullet is *Context*, and the fact it
got wrong makes the install cheaper rather than different.
