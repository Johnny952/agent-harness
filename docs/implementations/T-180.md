# T-180 — the credential kinds and `actions/secrets/`

ADR 456 *Consequences* task 1, with the rulings of ADR 459.

## What was built

`dispatcher/actions.py`:

- Constants `SECRETS`, `SECRET_MAX_AGE_SECONDS` (900), `GIT_TOKEN_RE`,
  `GIT_USERNAME_RE`, `LOGIN_CODE_RE`, `DEFAULT_GIT_USERNAME`. One copy of each
  shape, for the route and handler of later tasks to import.
- Kinds `git_token` (serial key `credential:git`) and `account_login`
  (`account:<name>`), neither spends quota, both recovery `interrupt` with
  ADR 456's lines. `_new_record` fills `params.username`; `_refuse_locked`
  gives the one-per 409s.
- `create(..., secret=)`: required and shaped for `git_token`, refused for
  other kinds, all before the lock. `_place` writes the secret
  (`_write_secret`: dot-named `O_EXCL` `0600` temp, fsync, rename) after the
  id is taken and before any record rename into `pending/`; a failure unlinks
  the secret too. `secrets/` is made `0700` on first write, not by
  `ensure_dirs`.
- `put_login_code` (400 shape, 409 not awaiting / already waiting, under
  `write.lock`), `take_secret` (no lock, once), `sweep_secrets` (under the
  lock: temps, orphans, older than 900 s).
- `finish` and `recover`'s "moved to done" branch unlink the secret.
- `read_all` and `find` are unchanged: they list `pending/claimed/done` by name.

`dispatcher/backup.py`: `NEVER_COPIED` gains `secrets`.

## Why this way

The sweep takes `write.lock` so it cannot unlink a token between the secret's
rename and the record's. `take_secret` takes none because a writer only
renames whole files in. The stdlib `secrets` module is already imported, hence
the constant is `SECRETS`.

## Ruled out

- `ensure_dirs` creating `secrets/`: it would change the read api's and a
  restore's view of `actions/`.
- Logging or echoing a value in any refusal.

## Tests

`tests/dispatcher/test_actions.py` (credential section): kinds and validation,
serial keys and recovery lines, one-per 409s, the secret rules at create,
`0600` before the record is pending (wrapped `os.rename`), failed rename
leaves no secret, take once, `put_login_code` 409s and shape, sweep, recovery
(claimed and final), finish of a cancelled token, `read_all`/`find` with a
secret present. `tests/dispatcher/test_backup.py`: `secrets` in the
no-credential shapes and a waiting secret absent from a copy.
