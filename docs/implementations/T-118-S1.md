# T-118-S1 — the `awaiting_review` status

Decisions are ADR 240 (`docs/decisions.md`); this records how it was built.

## What was done

- `dispatcher/tasks.py`: `AWAITING_REVIEW_STATUS`; `REVIEW_STATUSES` adds it;
  `mark_awaiting_review` (locked) moves `done` unmerged to `awaiting_review`,
  notifies, returns whether it moved, else leaves the task alone;
  `mark_merged` turns `awaiting_review` into `done`; `record_verdict`
  accepts `awaiting_review`, `conflict` and `done` unmerged, and refuses an
  `awaiting_review` task that is merged.
- `dispatcher/dispatcher.py`: `_notify_awaiting_review` became `_await_review`,
  a never-raising wrapper over `mark_awaiting_review` at the same call site;
  `_passed` sends a passing `conflict` task to `awaiting_review`;
  `_record_auto_approve` keeps `conflict` and `awaiting_review`, else `done`;
  `_file_split` refuses an `awaiting_review` parent (business.md *Task status*).
- `merge_on_done` is a deprecated alias: comments in `config.example.yaml`,
  `dispatcher/config.py` and at its branch in `run_task_cycle`. No behaviour
  change, no migration.
- Docs: `docs/plans/review.md` (status, *What exists today*, both *Narrowed*
  notes, step 1 built, the Conflict bullet) and `docs/plans/board-service.md`
  column table.

## Why this way

The cycle end already had one place that reasoned about "done and not merged";
moving the check into `tasks` under the task lock keeps the read and the write
one step, and the dispatcher keeps only the never-raise wrapper. Merge paths
needed no edit: all end in `record_merge` -> `mark_merged`.

## Tests

Full-cycle tests that asserted `done` with nothing merged now assert
`awaiting_review` (read per cause: refused pre-merge, refused auto approve,
unmerged cycle). New: `mark_awaiting_review` matrix, merge back to `done`,
`_await_review` never raising, `_record_auto_approve`, `_file_split`,
`record_verdict`, HTTP verdict and `/api/tasks`.

## Ruled out

- A hive migration of old `done` unmerged tasks (task says none; the console
  keeps listing them until S2/S3).
- Warning when `merge_on_done` is set: no behaviour to warn about yet.
