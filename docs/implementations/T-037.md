# T-037 — *Future work* cut down to its open gaps, a status list and a backlog

The root `README.md`'s *Future work* section ran about 990 lines and opened
with "Documented but **not designed or implemented**" over items that are
built, planned or overtaken. This task classifies every part of it against
the tree, rewrites the section short, and moves the text that is still open
and written nowhere else, word for word, into `docs/plans/backlog.md`.

This file is the design and the classification, written by the arquitecto on
2026-10-13 against base commit `7cc44ca`. The implementador adds *Where the
build differs from the design* and *Verified after the change* below it.

## Decisions

No ADR: the card puts `docs/decisions.md` out of scope, so they are here.

1. **No heading is removed and no item is renumbered.** `## Future work`,
   `### Known gaps (fix first)` and `### Prioritized` stay, and items 1 to 10
   keep their numbers and bold titles. Docs that say "README item 2" or
   "*Known gaps*" still land on a line that points onward.
2. **A landed piece is now a status line, not a kept spec.** Item 1's
   *Documenting is a method* bullet said the spec bullets under a
   *Prioritized* item "are never trimmed when a piece of it lands". This task
   retires that convention: the README holds status and a pointer, and the
   open text lives in the backlog.
3. **The unit that moves is a whole list element, or a run of whole
   sentences.** Where only part of a bullet is open, the backlog keeps the
   bullet's own italic title and marks each omission with `[…]`. No word is
   changed. A moved block is dedented to the left margin and its line breaks
   are kept.
4. **Text classified built, planned or superseded is not copied anywhere.**
   It stays in git: `git show 7cc44ca:README.md`. The backlog's intro says so.
5. **Links inside moved text are left as written.** They were written from
   the repo root (`docs/ROADMAP.md`), and "above" in them means the README.
   The backlog's intro says both. The pointers gate resolves a root-relative
   path from any doc, so they pass it.
6. **`docs/README.md` gets no row for the backlog.** The card keeps the task
   out of that file. It is declared as debt (*Left for later*).

## Classification

Each row was checked against the tree at `7cc44ca`, by the grep or read named
in *How each row was checked*. **built** cites code or a doc, **planned** a
plan or a `docs/ROADMAP.md` entry, **superseded** an ADR, **open** means not
built and not written down elsewhere. "Moves" means the text goes to the
backlog; every other row stays out of it.
