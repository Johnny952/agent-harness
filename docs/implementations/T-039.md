## Rules

1. **Point at the place that holds the words.** Open text: the backlog item
   by number (`docs/plans/backlog.md` item N, or its italic piece title).
   Planned text: the plan the README's status line names. Built text that
   was never moved: say it was the README's item N before T-037 and give
   `git show 7cc44ca:README.md`. Never cite a README item for prose it no
   longer has.
2. **A README section that still exists and still means what the sentence
   says is not stale.** `### Known gaps (fix first)` keeps one open bullet,
   *Unverified assumptions* (V0.7), and says the fixed gaps are recorded in
   `docs/ROADMAP.md` *Stage 1 — Fix the known gaps, then accept*. An
   instruction to add a confirmed gap there, or to remove a verified
   assumption from it, stays as written. `### Prioritized` keeps items 1 to
   10 by number and order, so "the README's order" stays too.
3. **Records are not edited.** Stale citations in them are listed under
   *Records left as written*.
4. **Wording is the implementador's; the target is not.** The replacement
   text below may be re-worded and re-wrapped to 80 columns, but each must
   name the target given here. Keep the surrounding sentences.
