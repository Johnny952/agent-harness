# T-185-S1 — `git_token.state` reads `not_mounted` under the Coolify compose

Rule: `docs/decisions.md` ADR 480.

## What

- `dispatcher/credentials.py`: `CONTAINER_MARKERS` (`/.dockerenv`,
  `/run/.containerenv`) and `_in_container()`; in `git_token_row` a missing
  path is `not_mounted` in a container, `absent` outside. The parent lookup is
  gone. Only the marker paths are `stat`ed; no secret is opened.
- `dispatcher/worker.py` is unchanged: the `not_mounted` sentence fits.
- Tests: `tests/dispatcher/test_credentials.py` pins the markers outside a
  container with an autouse fixture and covers the Coolify-like layout (parent
  holds `projects/`, no token), the Podman marker alone, and present / empty /
  directory in and out of a container. `test_worker_credentials.py`'s
  fixed-failures test built `not_mounted` from a missing parent; it now sets
  the markers per case.
- `docs/README.md` credentials row cites ADR 480.

## Why this way

The suite may itself run in a container, so every test sets
`credentials.CONTAINER_MARKERS` under `tmp_path`; the module global is read at
call time for that reason.

## Ruled out

`/proc/self/mountinfo` parsing and keeping the parent rule outside Docker: see
ADR 480 *Ruled out*.
