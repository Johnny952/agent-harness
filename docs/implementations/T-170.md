# T-170 — in-container process probe in the account reaper

Resolves `T-168-D1`. Design: `docs/decisions.md` ADR 429.

## What was built

- `dispatcher/docker_exec.py`: `PROCESS_PROBE_SCRIPT`, `PROCESS_PROBE_TIMEOUT_SECONDS`
  (30) and `task_process_seen(container, task_dir) -> bool | None`. One
  `docker exec -w /` running `sh -c <script> ia-harness-probe <task_dir>`; the
  script walks `/proc/[0-9]*`, `readlink`s each `cwd` and prints `seen` on the
  first one equal to or under `task_dir` (a ` (deleted)` suffix included), else
  `gone`. True on `seen`, False on `gone` with exit 0, None on anything else
  (other output, non-zero exit, `OSError`, `SubprocessError`).
- `dispatcher/dispatcher.py`: `_task_process_seen(cfg, account, task)` (None
  when the card has no `project`) and its one call in
  `reap_stale_busy_accounts`, in the branch where the heartbeat has expired and
  `_phase_may_be_running` is True. Only False releases; True/None keep the
  holder as ADR 411 did.
- `tests/dispatcher/conftest.py`: autouse stub of `_task_process_seen` returning
  None, so no test runs `docker`.
- `tests/dispatcher/test_process_probe.py` and one dispatch test in
  `test_dispatcher.py`.

## Why this way

The probe sits in the reaper only: every pick runs it before `acquire_lock`, so
`orphan_holders` and `reap_expired_locks` see the freed state without a second
round trip. A failed probe never frees anything (the ADR 411 race).

## Ruled out

- `pgrep`/`ps`: the agent image has no procps.
- Matching `claude` by argv: it does not name the task.
- The dispatch test lives in `test_dispatcher.py`, not the new file: that module
  carries the autouse fakes (`fake_git`, handoff resume) a full `dispatch_phase`
  needs.

## Verified

`python3 -m pytest tests -q`: 4707 passed, 15 skipped (before the script test
below was added; `test_process_probe.py` alone: 16 passed). The probe script
itself runs under the host's `sh` in a test against real `sleep` processes
(seen under the dir, gone for a sibling `T-10`). It was not run inside an agent
container: docker is refused in a phase.
