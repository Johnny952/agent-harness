## The change

- `PRESENT_DOCS` names `DEBT_INDEX` in place of `DEBT_DIR`.
- `RECORD_DOCS` gains `DEBT_DIR`.
- The comments on both tuples and the docstring of `is_record` say why, and
  cite ADR 62.

`is_record` is unchanged. `DEBT_INDEX` sits inside `DEBT_DIR` and the present
group wins, which is the layout `LEARNINGS_INDEX` already has inside
`LEARNINGS_DIR`.

### What stops being checked, and who answers for it

- **Open entries' files, old lines:** no longer read. Their present claim is
  the index row (what, where, fix), and the row is still read whole.
- **Resolved entries' files, old lines:** no longer read. They describe the
  tree as it was, which is what their first line already says.
- **Index rows:** still read whole, including each row's `Detail:` link, so
  renaming or deleting an entry file is still caught.
- **Lines a task adds to an entry file:** still checked, uncapped, as the task's
  own. One example is a *How it was resolved* section.
- **An entry file a task creates before the gate runs:** still read whole. An
  auditor's filing comes after the gate and is not read, the same as a learning.

No later task owes a broken pointer in an entry file's old lines. That is the
record rule ADR 35 already applies to decisions, notes, learnings and plans:
leave the sentence alone and record the disagreement somewhere newer. The one
who can fix such a pointer is the task that resolves the entry. It opens the
file through the row, and the same citations are in the row's where and fix
cells, which stay checked.

The shape reads no resolved status. The class is the path's alone, so a row and
a file that disagree about being resolved cannot change what the gate reads,
and no marker format was added.

## Ruled out

- **A resolved entry's file becomes a record.** The gate would have to read a
  status from the row's resolved prefix or from the file's first paragraph. It
  would need a rule for when the two disagree, and a file would change class
  over its life. Open entries would still feed the count.
- **Grep only the files the index lists as open.** This is the same shape as
  the first, with the same costs.

## Not done

- `_POINTER_LIMIT`, `_POINTER_CHUNK`, the other gates and the excuses are
  unchanged, as the card says.
- No stale citation in an old entry-file line was looked for or fixed. Under
  ADR 62 those are records.
