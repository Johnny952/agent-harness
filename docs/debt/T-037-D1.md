# T-037-D1 — The docs index does not name the backlog

**Resolved 2026-10-13 by T-037**, in its auditor phase: `docs/README.md`
*Docs* has a row for `docs/plans/backlog.md`, and the root `README.md` row
says *Future work* is now a status list with pointers.

**Origin:** introduced, declared by T-037's arquitecto and again by its
implementador in round 1.
**Ruling:** accepted by the revisor in round 1: the card kept
`docs/README.md` out of scope, the fix is one row plus one clause, and it
bites only a reader who uses the docs index to find the backlog.
**Card:** none — nothing mirrors a row (`docs/decisions.md` ADR 59).

## What

T-037 created `docs/plans/backlog.md` and cut the root `README.md`'s
*Future work* to a status list. `docs/README.md` *Docs* got no row for the
backlog, and its root `README.md` row still said "the known gaps and the
prioritized work. Long."

## Where it bites

A role reading `docs/README.md` *Docs* to find open, unplanned work, or a
task adding a doc under `docs/plans/`.

## Why it stayed

The card kept the implementing phases to `README.md`, the backlog, the
implementation note, debt and learnings. The docs index is the auditor's to
keep.

## Cost of leaving it

Roles that start at `docs/README.md` would not learn the backlog exists; only
the root `README.md` pointed at it.

## Fix

One row for `docs/plans/backlog.md` and one clause on the `README.md` row in
`docs/README.md` *Docs*. Taken as declared, by the auditor that filed it.
