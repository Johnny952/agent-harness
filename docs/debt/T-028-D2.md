# T-028-D2 — the root `README.md` still offers a board, and the agent image still installs `mcp`

**Origin:** introduced, declared by T-028's arquitecto and by the
implementador in rounds 1 and 2.
**Ruling:** accepted by the revisor in both rounds: a large README rewrite and
an image change no phase can prove, and the startup error names the ADR.
**Card:** none — nothing mirrors a row (`docs/decisions.md` ADR 59).

## What

Two leftovers of the board seam T-028 removed, outside the files its card
named:

- The root `README.md` still describes the optional board in the present
  tense: the architecture sketch, the *Vibe Kanban* component bullet, the
  `vibe-kanban` compose service and its `kanban` profile, the passage *The
  board, if you want one* with both config blocks and `--kanban-issue-id`,
  the debt-card passages, and the known-limits entries about the client.
- `pyproject.toml` and `docker/agent/Dockerfile` still install `mcp`, which
  only the deleted client module imported, and the Dockerfile's comment
  names that module.

## Where it bites

An operator following `README.md` to configure a board, or a task editing
the agent image's pip list or `pyproject.toml`'s dependencies. Also any task
removing a config key that reads
`docs/learnings/a-config-key-has-three-homes.md`: the README is the third
home, and here it is the one left behind.

## Why it stays

The card keeps T-028 to named files. The README's board prose runs through
more than a dozen passages, and an image change cannot be proved inside a
phase (`docker` is refused there).

## Cost of leaving it

An operator who follows the README adds a `vibe_kanban` or `local_board`
block and gets a startup error naming the key and ADR 59, or passes a flag
that is now a usage error. The agent image carries one unused package.

## Fix

One docs task rewrites the README's board passages against ADR 59 and drops
`mcp` from `pyproject.toml` and `docker/agent/Dockerfile`, with its comment.
Grep `README.md` for `kanban`, `local_board` and "the board" to find them
all. The image half needs a build by a human or a task whose card grants it.
