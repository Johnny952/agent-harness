# T-008-D3 — `docs/plans/board.md`'s Status paragraph still calls Phase 0 queued

**Origin:** introduced by T-008. **Status:** open. **Ruling:** accepted by the
revisor, rounds 1 and 2.

## What

`docs/plans/board.md`'s Status paragraph reads "Phase 0 is specified below and
queued as T-008, to be built by …". Phase 0 is built and on this branch, so the
plan's own front matter contradicts the code it planned.

## Where it bites

A task or an operator reading that paragraph to decide whether Phase 0 exists,
and concluding it is still queued. Phases 1–6 all start from that file.

## Why it stays

The task's "Out of scope" names `docs/plans/board.md` as the spec and forbids
touching it: editing the file a task is measured against, mid-task, moves the
target. Nobody in T-008 was allowed to close this.

## Cost of leaving it

The plan says Phase 0 is pending while `dispatcher/vibe_kanban_client.py` has
`LocalBoardClient` in it. A reader who trusts the plan either re-specifies work
that exists or waits for it.

## Fix

One line in that Status paragraph: Phase 0 landed in T-008, pointing at
`docs/decisions.md` ADR 1 and `docs/implementations/T-008.md`. It belongs to
whoever opens Phase 1 — the first task allowed to edit the plan. Entry
`T-008-D1` is the only Phase 0 item still open in the code.
