# T-036-D1 — The present docs' scope reads every debt file whole for ever

**Resolved 2026-10-13 by T-038.** See *How it was resolved*; the sections
before it describe the tree as it was.

**Origin:** found, declared by T-036's implementador in round 1; the
arquitecto named the same thing under its risks.
**Ruling:** accepted by the revisor in round 1: the scope belongs to
`dispatcher/project_docs.py`, which T-036's card put out of reach, this index
carried no row for it, and the limit of 1000 buys about fifty tasks.
**Card:** none — nothing mirrors a row (`docs/decisions.md` ADR 59).

## What

The pointers gate reads the docs `PRESENT_DOCS` in
`dispatcher/project_docs.py` names whole on every run, and the debt directory
is one of them. A debt entry's file stays in that directory after the entry is
resolved, because a resolved row is marked and never deleted. So every
citation in every debt file, open or resolved, is checked on every task for
as long as the project lives, and the number of unique (doc, token) pairs the
present docs give only grows.

Measured at T-036's base (`32d13e9`): 400 pairs in all, 275 of them from the
debt directory's 33 files. `docs/decisions.md` ADR 35 counted 151 for the
whole scope. Growth has been about 12 pairs per task.

T-036 moved the limit from 400 to 1000 and made it bound only the present
docs (`docs/decisions.md` ADR 61). That moves the day the limit bites; it does
not change what feeds it.

## Where it bites

A task whose run logs `present-doc citations went unchecked`, or one that
finds the present-doc pair count nearing `_POINTER_LIMIT` in
`dispatcher/gates.py`. Also a task changing `PRESENT_DOCS` or `is_record` in
`dispatcher/project_docs.py`, which is where the fix lands. Not a task that
only adds a debt file or a row: each adds a few pairs and nothing else.

## Why it stays

What counts as a present doc is `dispatcher/project_docs.py`'s to decide, and
T-036's card kept that file out of scope. The gate's own half, the order and
the limit, is what T-036 did.

## Cost of leaving it

Past the limit, a broken citation in a present doc goes unreported, and which
ones are skipped is the order `grep -r` walks the debt directory, not a
choice anyone made. Until then the cost is container calls: `_missing` asks
`ls` once per `_POINTER_CHUNK` paths, 4 calls on this tree today and at most
20 at the limit. A task's own citations are not at risk either way: since
ADR 61 they are checked first and never dropped.

## Fix

Decide in `dispatcher/project_docs.py` whether a resolved debt file is still
a present doc (`docs/decisions.md` ADR 61, *Consequences*). Two shapes were
named and neither was weighed:

- a resolved entry's file becomes a record, so only the lines a task adds to
  it are checked. The gate then has to know which entries are resolved, which
  today only the index row and the file's first line say;
- the debt index stays a present doc and the entry files become records,
  open or not.

Either one is an ADR of its own, narrowing ADR 35's scope. Count the pairs
before and after with the gate's own steps
(`docs/implementations/T-036.md`, *The count*).

## How it was resolved

**Resolved 2026-10-13 by T-038** (`docs/decisions.md` ADR 62,
`docs/implementations/T-038.md`).

The second shape was taken. In `dispatcher/project_docs.py`, `PRESENT_DOCS`
names `DEBT_INDEX` in place of `DEBT_DIR`, and `RECORD_DOCS` gains `DEBT_DIR`.
`is_record` did not change: the present group already wins the overlap, as it
does for the learnings index. So the index rows are read whole every task, and
every entry file, this one included, is a record. Only the lines a task adds to
it are checked. No status is read and no marker was added, so a row and a file
that disagree about being resolved cannot change what the gate reads.

The first shape was rejected because it makes the class depend on content.
Resolved files would turn into records, but the open ones would still feed the
count.

Counted with the gate's own steps on T-038's tree: 413 present pairs before,
285 of them from the debt directory. After the change there are 193, and the
debt index gives 65 of them. `dispatcher/gates.py` did not change.
